Fishing Store MVP
Це сучасний інтернет-магазин рибальських товарів, побудований на Angular 19. Проект демонструє навички роботи з компонентами, сервісами, реактивним керуванням станом та інтеграцією з зовнішніми API.

[Fishing store](https://vitiok2021.github.io/angular-fishing-store/)

🛠 Стек технологій
Core: Angular 19 (Standalone components)

State Management: RxJS, Signals, BehaviorSubject (для кошика та обраного)

Styling: SCSS (BEM methodology, Flexbox/Grid)

Backend: MockAPI (RESTful API для товарів)

Deployment: GitHub Pages

Основний функціонал
Каталог товарів: Динамічне завантаження товарів з API.

Детальна сторінка товару: Динамічна маршрутизація (/product/:id) з відображенням характеристик та галереї.

Керування кошиком: Додавання/видалення товарів, автоматичний підрахунок суми в реальному часі.

Список обраного: Можливість відмічати улюблені приманки.

Адмін-панель: Інтерфейс для керування асортиментом (імітація).

Responsive Design: Сайт повністю адаптований під мобільні пристрої та планшети.

Як запустити проект локально
Клонуйте репозиторій:

Bash
git clone https://github.com/Vitiok2021/angular-fishing-store.git
Встановіть залежності:

Bash
npm install
Запустіть сервер для розробки:

Bash
ng serve
Відкрийте http://localhost:4200/ у браузері.
